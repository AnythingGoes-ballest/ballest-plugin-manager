Descriptions and examples for the API reference. tools/gen_api_docs.py matches every function registered in
src/host/api.cpp to an entry here and refuses to build the docs if one is missing or one names nothing.

Format:
  @@ <Namespace> or @@ <Namespace>::<Type>    the introduction at the top of that section (markdown)
  == <key> [<key> ...]                        one entry; several keys share it (Log::Info, UI::Window.AddText,
                                              UI::Window.visible for a property)
  description (markdown), then a line "--", then the example (AngelScript) up to the next @@ or ==

@@ Log
Writes to the host log, `%LOCALAPPDATA%\Ballest\Saved\PluginManager\host.log`. It's recreated each time the game
starts and is the first place to look when a plugin misbehaves. Every line is tagged with the plugin's id.

== Log::Info
Writes an information line to the host log.
--
// Shows up in host.log as "[info] [my-plugin] loaded, 3 tracks remembered"
Log::Info("loaded, " + trackCount + " tracks remembered");

== Log::Warn
Writes a warning line to the host log. Use it for something that went wrong but that the plugin can carry on from.
--
// A saved value that can't be read: warn and fall back to the default
if (parseFloat(saved) <= 0)
    Log::Warn("saved size '" + saved + "' is not a size; using 56");

== Log::Error
Writes an error line to the host log. The plugin keeps running; this only records the problem.
--
// Something the player should report
Log::Error("could not find the timer window after a map change");

== Log::LineCount
How many lines have been written to the log this session, by the host and every plugin. Use it with
`Log::Line` to show the log inside the game.
--
// Only rebuild a log view when something new was written
uint count = Log::LineCount();
if (count != shownLines)
{
    RebuildLogView();
    shownLines = count;
}

== Log::Line
One line of this session's log, numbered from 0. Only the most recent lines are kept in memory. An older line comes
back as `""`.
--
// The last 20 lines, oldest first
string text;
uint count = Log::LineCount();
for (uint i = count > 20 ? count - 20 : 0; i < count; i++)
    text += Log::Line(i) + "\n";
logArea.text = text;

@@ Host
The plugin host itself: its version, a clock, and opening web pages.

== Host::Version
The host's version, for example `"0.6.0"`. To require a minimum version, set `min_host` in `info.toml` instead:
older hosts then refuse to install or run the plugin.
--
// Shown in an about panel
aboutText.text = "running on plugin host " + Host::Version();

== Host::Time
Seconds of real time since the plugin host started, which is when the game started. It keeps counting through
pauses and loading screens. Use the difference between two readings to time things.
--
// Do something at most once every 5 seconds
if (Host::Time() - lastSave > 5.0)
{
    Save();
    lastSave = Host::Time();
}

== Host::OpenUrl
Opens a page in the player's web browser. Only `https://github.com/` addresses are allowed. Anything else is refused
and logged.
--
// A "source" button that opens the plugin's repo
if (sourceButton.Clicked())
    Host::OpenUrl("https://github.com/AnythingGoes-ballest/ballest-grind-timer-plugin");

@@ Plugins
The plugins currently loaded, in load order. Index `i` runs from `0` to `Count() - 1`. Installing, removing and
updating the host are only allowed for the plugin manager. For any other plugin the call does nothing and a warning
is logged.

== Plugins::Count
How many plugins are loaded.
--
// List every loaded plugin in the log
for (uint i = 0; i < Plugins::Count(); i++)
    Log::Info(Plugins::Name(i) + " " + Plugins::Version(i));

== Plugins::Id
The plugin's id: its folder name under `plugins\`.
--
// Find where another plugin sits in the list
int IndexOf(const string &in id)
{
    for (uint i = 0; i < Plugins::Count(); i++)
        if (Plugins::Id(i) == id)
            return int(i);
    return -1;
}

== Plugins::Name
The plugin's display name, `name` in its `info.toml`.
--
// "Grind Timer"
string title = Plugins::Name(i);

== Plugins::Version
The plugin's version, `version` in its `info.toml`.
--
// "Grind Timer   0.2.1"
string row = Plugins::Name(i) + "   " + Plugins::Version(i);

== Plugins::Status
The plugin's status: `"running"`, or why it stopped, for example `"stopped: exceeded its 30 ms budget"` or
`"exception: Null pointer access in void Update(float) line 10"`.
--
// Flag plugins that have stopped
if (Plugins::Status(i) != "running")
    Log::Warn(Plugins::Name(i) + ": " + Plugins::Status(i));

== Plugins::Author
The plugin's author, `author` in its `info.toml`.
--
string byline = "by " + Plugins::Author(i);

== Plugins::Description
The plugin's one-line description, `description` in its `info.toml`.
--
// Name on one line, description under it
panel.AddLine(Plugins::Name(i));
panel.AddLine(Plugins::Description(i));

== Plugins::Icon
The full path of the plugin's icon image, or `""` if it has none. It can be passed straight to `AddImage`.
--
// The plugin's icon, or the default one
string icon = Plugins::Icon(i) != "" ? Plugins::Icon(i) : Plugins::DefaultIcon();
window.AddImage(icon, 48, 48);

== Plugins::Essential
Whether the plugin is essential (`essential = true` in `[meta]`). Essential plugins are part of the host's own setup,
like the plugin manager, and can't be removed.
--
// No remove button for essential plugins
removeButton.visible = !Plugins::Essential(i);

== Plugins::IsInstalled
Whether a plugin with this id is loaded.
--
// Only offer the replay extras if the Replay Manager is there too
bool haveReplayManager = Plugins::IsInstalled("replay-manager");

== Plugins::InstalledVersion
The version of the loaded plugin with this id, or `""` if there isn't one.
--
// Compare with the registry's version to offer an update
bool outdated = Plugins::IsInstalled(id) && Plugins::InstalledVersion(id) != Registry::Version(i);

== Plugins::Install
**Plugin manager only.** Downloads a plugin from the registry, checks every file's SHA-256, and starts it without a
restart. Use `Pending(id)` to follow the progress.
--
// The browser's install button
if (installButton.Clicked())
    Plugins::Install(Registry::Id(i));

== Plugins::Remove
**Plugin manager only.** Stops a plugin, removes its UI and deletes its folder.
--
if (removeButton.Clicked())
    Plugins::Remove(id);

== Plugins::Pending
How an install or removal is going: `""` (nothing pending), `"installing"`, `"removing"`, or `"error: ..."`.
--
// Show progress on the button
string state = Plugins::Pending(id);
installButton.label = state == "" ? "install" : state;

== Plugins::DefaultIcon
The path of the default icon the plugin manager ships, used for plugins that have no icon of their own.
--
string icon = Plugins::Icon(i) == "" ? Plugins::DefaultIcon() : Plugins::Icon(i);

== Plugins::Enabled
Whether the player has the plugin turned on. A plugin turned off stays installed and listed (its status is `off`)
but doesn't run, and the plugins that depend on it wait for it.
--
string state = Plugins::Enabled(i) ? "on" : "off";

== Plugins::SetEnabled
**Plugin manager only.** Turns a plugin off or back on, straight away and for later launches. Its settings and saved
data are kept. The plugin manager itself can't be turned off.
--
Plugins::SetEnabled("grind-timer", false);

== Plugins::Folder
The running plugin's own folder, ending in a backslash. Use it to name files the plugin ships, such as images for
[cosmetics](cosmetics.md).
--
string ball = Plugins::Folder() + "ball.png";

== Plugins::OpenFolder
Opens the plugins folder in File Explorer.
--
if (folderButton.Clicked())
    Plugins::OpenFolder();

== Plugins::UpdateHost
**Plugin manager only.** Downloads the newest host the registry lists, checks it, and puts it in place. It takes over
the next time the game starts. Use `HostUpdateState()` to follow the progress.
--
if (updateButton.Clicked() && Registry::HostVersion() != Host::Version())
    Plugins::UpdateHost();

== Plugins::HostUpdateState
How a host update is going: `""`, `"downloading"`, `"restart"` (ready, restart the game), or `"error: ..."`.
--
if (Plugins::HostUpdateState() == "restart")
    statusText.text = "restart the game to finish the update";

@@ Settings
Every loaded plugin's `[Setting]` variables, as a flat list. Index `i` runs from `0` to `Count() - 1`. A plugin
normally just reads and assigns its own setting variables; these functions are for building a settings page.
`Set` and `Reset` are for the plugin manager only. See [Settings](../../guides/settings.md).

== Settings::Count
How many settings there are across all loaded plugins.
--
for (uint i = 0; i < Settings::Count(); i++)
    Log::Info(Settings::Plugin(i) + ": " + Settings::Name(i) + " = " + Settings::Get(i));

== Settings::Plugin
The id of the plugin that owns the setting.
--
// Only this plugin's settings
if (Settings::Plugin(i) == "grind-timer")
    AddSettingRow(i);

== Settings::Name
The setting's display name (`name=` in its `[Setting]` tag, or the variable's name).
--
label.text = Settings::Name(i);

== Settings::Description
The setting's description (`description=` in its tag), or `""`.
--
if (Settings::Description(i) != "")
    label.text += "\n" + Settings::Description(i);

== Settings::Kind
The variable's type: `"bool"`, `"int"`, `"uint"`, `"float"`, `"double"` or `"string"`.
--
// An on/off button for a bool, a text box for everything else
if (Settings::Kind(i) == "bool")
    window.AddButton(Settings::Get(i) == "true" ? "on" : "off");
else
    window.AddTextInput(200, "type a value, Enter");

== Settings::Hidden
Whether the setting is tagged `hidden`. Hidden settings are saved, but a settings page doesn't show them.
--
if (Settings::Hidden(i))
    continue;

== Settings::HasRange
Whether the setting has both `min` and `max`, so it can be shown as a slider.
--
if (Settings::HasRange(i))
    window.AddSlider(360);

== Settings::Min
The setting's `min` (meaningful when `HasRange`).
--
// Slider position (0..1) for the current value
float fraction = float((parseFloat(Settings::Get(i)) - Settings::Min(i)) / (Settings::Max(i) - Settings::Min(i)));

== Settings::Max
The setting's `max` (meaningful when `HasRange`).
--
// Value for a slider position (0..1)
double value = Settings::Min(i) + slider.value * (Settings::Max(i) - Settings::Min(i));

== Settings::Get
The setting's current value as text (`"true"`, `"56"`, `"0.35"`, ...).
--
valueText.text = Settings::Get(i);

== Settings::IsDefault
Whether the setting is at its default value (the value the variable starts with in the script).
--
// Only show "reset" when there's something to reset
resetButton.visible = !Settings::IsDefault(i);

== Settings::Set
**Plugin manager only.** Sets another plugin's setting from text. Numbers are clamped to `min`/`max`. Returns false
if the text isn't a value of the setting's type. The owner's `OnSettingsChanged()` runs before its next `Update`.
--
if (input.Submitted() && !Settings::Set(i, input.text))
    Log::Warn("not a value for " + Settings::Name(i) + ": " + input.text);

== Settings::Reset
**Plugin manager only.** Puts a setting back to its default.
--
if (resetButton.Clicked())
    Settings::Reset(i);

@@ Registry
The plugin registry: the list of plugins the game can install, read from `registry.json` on GitHub. Index `i` runs
from `0` to `Count() - 1` once `State()` is `"ready"`.

== Registry::Refresh
Downloads the registry again. It's already loaded once when the game starts.
--
if (refreshButton.Clicked())
    Registry::Refresh();

== Registry::State
`""` (not asked for yet), `"loading"`, `"ready"`, or `"error: ..."`.
--
if (Registry::State() != "ready")
{
    statusText.text = "registry: " + (Registry::State() == "" ? "not loaded" : Registry::State());
    return;
}

== Registry::Count
How many plugins the registry lists.
--
countText.text = Registry::Count() + " in the registry";

== Registry::Id
The listed plugin's id, the name its folder will have.
--
bool installed = Plugins::IsInstalled(Registry::Id(i));

== Registry::Name
The listed plugin's display name.
--
row.text = Registry::Name(i) + "   " + Registry::Version(i);

== Registry::Description
The listed plugin's one-line description.
--
panel.AddLine(Registry::Description(i));

== Registry::Author
The listed plugin's author.
--
string byline = "by " + Registry::Author(i);

== Registry::Version
The newest version the registry lists for the plugin.
--
bool update = Plugins::InstalledVersion(Registry::Id(i)) != "" &&
              Plugins::InstalledVersion(Registry::Id(i)) != Registry::Version(i);

== Registry::Page
The plugin's GitHub page, `https://github.com/<owner>/<repo>`.
--
if (githubButton.Clicked())
    Host::OpenUrl(Registry::Page(i));

== Registry::Icon
The path of the downloaded copy of the plugin's icon, or `""` while it hasn't been downloaded (or if there is none).
--
window.AddImage(Registry::Icon(i) != "" ? Registry::Icon(i) : Plugins::DefaultIcon(), 64, 64);

== Registry::HostVersion
The newest plugin host version the registry lists.
--
if (Registry::HostVersion() != "" && Registry::HostVersion() != Host::Version())
    statusText.text = "plugin manager " + Registry::HostVersion() + " is available";

@@ Console
Runs the host's own commands, the same ones as the in-game console (footer **plugins** > **console**).
They're for measuring and debugging. The list is in `src/host/testchannel.hpp`.

== Console::Run
Runs a host command on the next frame. Its output goes to the log.
--
// Log the current view target (the camera the game is looking through)
Console::Run("viewtarget");

@@ Storage
This plugin's saved values: text by key, kept across launches, one file per plugin in
`%LOCALAPPDATA%\Ballest\Saved\PluginManager\storage\`. Each plugin only sees its own. Settings are saved
automatically; use Storage for everything else.

== Storage::Get
The saved value for a key, or `fallback` if there's none.
--
// Load on start
void Main()
{
    seconds = parseFloat(Storage::Get("seconds", "0"));
    paused = Storage::Get("paused", "false") == "true";
}

== Storage::Set
Saves a value for a key. A changed value is written to disk straight away (setting the same value again writes
nothing), so don't save a value that changes every frame. Save it every few seconds instead.
--
// Save every 5 seconds while something changed
if (dirty && Host::Time() - lastSave > 5.0)
{
    Storage::Set("seconds", formatFloat(seconds, "", 0, 3));
    lastSave = Host::Time();
    dirty = false;
}

@@ UI
User interface, built from the game's own widgets so it looks like part of the game. A plugin creates
**footer buttons**, **panels** above the footer, and **windows**. The handles it gets back stay valid for the
plugin's whole life: when the game rebuilds its menus or loads a map, the host rebuilds the widgets behind them.
Build the UI once in `Main()`; in `Update()` read what the player did and change what's shown. See
[Windows and widgets](../../guides/ui.md).

== UI::SetCursorVisible
Asks for the mouse cursor to be shown (`true`) or releases that request (`false`). The cursor shows while any
plugin asks for it.
--
// A window you can click while it's open
window.visible = open;
UI::SetCursorVisible(open);

== UI::CursorShown
Whether the mouse cursor is on screen at all: because a plugin asked, or because the game shows it (pause menu,
menus).
--
// Only show the buttons when they can be clicked
pauseButton.visible = UI::CursorShown();

== UI::ResetPositions
Puts every movable window of a plugin back where the plugin placed it, forgetting where the player dragged it.
--
if (resetPositionButton.Clicked())
    UI::ResetPositions("grind-timer");

== UI::HasMovable
Whether a plugin has any window the player can drag.
--
resetPositionButton.visible = UI::HasMovable(Settings::Plugin(i));

== UI::AddFooterButton
Adds a button to the game's footer bar, the one at the bottom of the main menu, the in-race menus and the track
editor. It stays there in every menu.
--
UI::FooterButton@ button;

void Main()
{
    @button = UI::AddFooterButton("timer");
}

void Update(float dt)
{
    if (button.Clicked())
        panel.visible = !panel.visible;
}

== UI::CreatePanel
Creates a panel: a small box of lines and buttons that opens above the footer. It starts hidden.
--
UI::Panel@ panel = UI::CreatePanel();
panel.title = "grind timer";
panel.AddLine("0:42:17 on this track");
UI::FooterButton@ resetButton = panel.AddButton("reset");

== UI::CreateWindow
Creates a window: a box on screen that holds rows of widgets. It starts visible, centred at the bottom of the
screen 40 pixels above the edge, with a black background at 65% opacity.
--
UI::Window@ window = UI::CreateWindow();
window.SetAnchor(1, 0);        // top right of the screen
window.SetPivot(1, 0);         // ... by the window's own top right corner
window.SetOffset(-40, 40);     // 40 pixels in from the edges
window.AddText("hello", 24);

@@ UI::FooterButton
A button in the footer bar (from `UI::AddFooterButton`), or in a panel (from `Panel.AddButton`).

== UI::FooterButton.Clicked
True once per click. Reading it clears it, so check it in one place each frame.
--
if (button.Clicked())
    panel.visible = !panel.visible;

== UI::FooterButton.hovered
**Read only.** Whether the mouse is over the button.
--
// Show a hint while hovering
hintText.visible = button.hovered;

== UI::FooterButton.label
**Write only.** The button's text.
--
button.label = paused ? "start" : "pause";

@@ UI::Panel
A box of lines and buttons above the footer (from `UI::CreatePanel`).

== UI::Panel.Clear
Removes every line (buttons stay).
--
// Rebuild the lines when something changes
panel.Clear();
for (uint i = 0; i < names.length(); i++)
    panel.AddLine(names[i]);

== UI::Panel.AddLine
Adds a line of text under the ones already there.
--
panel.AddLine("restarts: " + restarts);

== UI::Panel.title
**Write only.** The heading at the top of the panel.
--
panel.title = "plugins";

== UI::Panel.visible
Whether the panel is open.
--
if (button.Clicked())
    panel.visible = !panel.visible;

== UI::Panel.AddButton
Adds a button at the bottom of the panel. It's the same type as a footer button.
--
UI::FooterButton@ openButton = panel.AddButton("open");
// later, in Update:
if (openButton.Clicked())
    window.visible = true;

@@ UI::Window
A box on screen holding widgets in rows (from `UI::CreateWindow`). Widgets are added left to right; `NewRow()`
starts the next row. A window can also have a header, cards, a sidebar and several views (one shown at a time),
like the plugin manager's menu.

== UI::Window.SetAnchor
The point of the screen the window is placed from, as fractions: `(0, 0)` top left, `(0.5, 0.5)` centre,
`(1, 1)` bottom right.
--
window.SetAnchor(0.5, 0);      // top centre of the screen

== UI::Window.SetPivot
The point of the window that sits on the anchor, as fractions of the window's size.
--
// Centred horizontally at the top of the screen
window.SetAnchor(0.5, 0);
window.SetPivot(0.5, 0);

== UI::Window.SetOffset
Moves the window from its anchor, in pixels.
--
window.SetAnchor(0, 0);
window.SetOffset(40, 40);      // 40 pixels from the top left corner

== UI::Window.SetBackground
The window's background colour, red, green, blue and opacity from 0 to 1. Opacity `0` removes the background.
--
window.SetBackground(0, 0, 0, 0.35f);   // a light dark tint

== UI::Window.visible
Whether the window is shown.
--
// Only on a track
window.visible = Race::OnTrack();

== UI::Window.AddText
Adds a text. `size` is the font height in pixels (16 if left out).
--
UI::Text@ timeText = window.AddText("0:00:00", 56);
timeText.SetColor(0.24f, 1, 0.35f, 1);

== UI::Window.AddButton
Adds a button with a text label.
--
UI::Button@ resetButton = window.AddButton("reset");

== UI::Window.AddIconButton
Adds a button that shows a drawn icon: `"play"`, `"pause"`, `"down"` or `"up"` (arrows, for showing and hiding
more of a window). Change it with `icon`.
--
UI::Button@ playButton = window.AddIconButton("pause");
// later: playButton.icon = paused ? "play" : "pause";

== UI::Window.AddSlider
Adds a slider `width` pixels wide. Its value runs from 0 to 1.
--
UI::Slider@ slider = window.AddSlider(600);

== UI::Window.AddDropdown
Adds a dropdown `width` pixels wide. Add its choices with `AddOption`.
--
UI::Dropdown@ speed = window.AddDropdown(90);
speed.AddOption("1x");
speed.AddOption("2x");
speed.selected = 0;

== UI::Window.AddSpace
Adds empty space `width` pixels wide. `0` takes up all the leftover room in the row, pushing the widgets after it to
the right edge.
--
// Label on the left, button on the right
window.AddText("Show timer");
window.AddSpace(0);
window.AddButton("on");

== UI::Window.NewRow
Starts a new row: widgets added afterwards go underneath.
--
window.AddText("0:42:17", 56);
window.NewRow();
window.AddText("restarts 36", 22);

== UI::Window.StartSidebar
Widgets added after this stack in a column `width` pixels wide on the left of the window, until `StartMain()`.
--
window.StartSidebar(220);
UI::Button@ logNav = window.AddButton("console");
UI::Button@ pluginsNav = window.AddButton("plugins");
window.StartMain();

== UI::Window.StartMain
Ends the sidebar: widgets added after this go back into the rows on the right.
--
window.StartSidebar(220);
window.AddButton("settings");
window.StartMain();
window.AddText("settings", 28);

== UI::Window.SetScreenSize
Gives the window a fixed size as fractions of the screen. Without one, the window is as big as its contents.
--
window.SetScreenSize(0.8f, 0.85f);   // most of the screen, for a menu

== UI::Window.StartView
Starts a new view and returns its number. Widgets added afterwards belong to it. Only one view shows at a time,
chosen with `ShowView`.
--
int logView = window.StartView();
window.AddTextArea(900, 600);
int settingsView = window.StartView();
window.AddText("settings");
window.ShowView(logView);

== UI::Window.SetBlocksClicks
With `true`, clicks on the window never reach the game underneath it.
--
menu.SetBlocksClicks(true);    // a menu over the game

== UI::Window.AddCheckBox
Adds a tick box with a label next to it. `size` is the label's font height (16 if left out).
--
UI::CheckBox@ xAxis = window.AddCheckBox("X", 16);
xAxis.checked = true;

== UI::Window.DockInEditorDetails
Makes the window a section of the track editor's details panel, under the game's transform and paint sections, shown
while pieces are selected. Call it before adding widgets. `SetAnchor`, `SetOffset` and `movable` don't apply to a
docked window.
--
UI::Window@ section = UI::CreateWindow();
section.DockInEditorDetails();
section.SetBackground(0, 0, 0, 0);
section.AddText("rotated copy", 18);

== UI::Window.StartHeader
Widgets added after this go into rows above the views, shown whichever view is open, until the next `StartView`.
Use it for tabs or a toolbar shared by every view.
--
window.StartHeader();
window.AddText("plugins", 28);
UI::Button@ installedTab = window.AddButton("installed");
UI::Button@ browseTab = window.AddButton("browse");
int installedView = window.StartView();     // the header ends here

== UI::Window.StartCard
Rows added after this share one rounded box, a card, until `EndCard()`. `NewRow()` inside a card adds another
row to the same card.
--
// A card with a title row and a description row
window.StartCard();
window.AddImage(Plugins::Icon(i), 52, 52);
window.AddText(Plugins::Name(i), 21);
window.AddSpace(0);
UI::Button@ settingsButton = window.AddButton("settings");
window.NewRow();
window.AddText(Plugins::Description(i), 16);
window.EndCard();

== UI::Window.EndCard
Ends the card started by `StartCard()`. Widgets added afterwards go on a new row below it.
--
window.StartCard();
window.AddText("Show timer", 19);
window.EndCard();
window.StartCard();                     // the next card
window.AddText("Time size", 19);
window.EndCard();

== UI::Window.SetCardBackground
The colour of this window's cards, red, green, blue and opacity from 0 to 1.
--
window.SetBackground(0.05f, 0.055f, 0.07f, 0.97f);
window.SetCardBackground(0.11f, 0.12f, 0.15f, 1);    // a little lighter than the window

== UI::Window.zOrder
Which windows are in front: higher is in front. Windows start at 100, the plugin manager's menu uses 500, and footer
panels are at 1000.
--
menu.zOrder = 500;    // above other plugins' windows

== UI::Window.movable
With `true`, the player can drag the window whenever the cursor is on screen. Where they leave it is saved, and
**reset position** in the settings puts it back. Set it after `SetOffset`: that's the position reset returns to.
--
timerWindow.SetOffset(40, 40);
timerWindow.movable = true;

== UI::Window.ShowView
Shows one view (a number from `StartView`) and hides the others.
--
if (logNav.Clicked())
    window.ShowView(logView);

== UI::Window.SetScrolling
Makes a view scroll (mouse wheel or its scroll bar) when its rows are taller than the window, such as a long list of
cards. Not for a view with a text area of height 0 (that one fills the height instead).
--
int list = window.StartView();
window.SetScrolling(list, true);

== UI::Window.ClearView
Removes every widget in a view. Widgets added afterwards go into that view, so it can be rebuilt.
--
// Rebuild the settings view when the list of settings changes
window.ClearView(settingsView);
for (uint i = 0; i < Settings::Count(); i++)
    AddSettingRow(i);

== UI::Window.AddImage
Adds an image from a PNG file (full path), shown `width` by `height` pixels.
--
window.AddImage(Plugins::Icon(i), 48, 48);

== UI::Window.AddTextArea
Adds a scrolling text box `width` by `height` pixels. `size` is the font height (14 if left out). While it's
scrolled to the end, it follows new text.
--

@@ Input
The keyboard, mouse and controller, read only while the game window has focus. While the player is typing in a
plugin's text box, every key reads as up except `Input::Escape`, so Escape can still close a menu (for the game's own
text boxes, check `Editor::Typing()`). Keys are `Input::Key` values: named keys such as `Input::F5`, `Input::PageUp`,
`Input::Backspace`, `Input::MouseBack`, `Input::A` to `Input::Z`, `Input::N0` to `Input::N9` for the number row,
`Input::Numpad0` to `Input::Numpad9`, and controller buttons: `Input::PadA`, `PadB`, `PadX`, `PadY`, `PadLB`, `PadRB`,
`PadLT`, `PadRT`, `PadL3`, `PadR3`, `PadView`, `PadMenu`, the D-pad (`PadUp`, `PadDown`, `PadLeft`, `PadRight`) and
the left stick pushed a direction (`PadStickUp`, ...). Controllers are read with XInput (Xbox pads, and most others
through Steam Input). The Down arrow is `Input::Key::Down`, since `Input::Down` is also the function below.

== Input::Pressed
True in the frame the key goes down.
--
// F6 toggles the window
if (Input::Pressed(Input::F6))
    window.visible = !window.visible;

== Input::Down
True for as long as the key is held.
--
// Only snap once the drag has finished
if (!Input::Down(Input::MouseLeft))
    SnapSelection();

== Input::AnyPressed
A key that went down this frame, or `Input::None`: for letting the player choose a key.
--
Input::Key k = Input::AnyPressed();
if (k != Input::None)
    Log::Info("pressed " + Input::Name(k));

== Input::Name
A key's name, as its `Input::Key` value is written without `Input::` ("F5", "PageUp", "PadA").
--
hint.text = "save: " + Input::Name(saveKey);

@@ Race
The race the player is in.

== Race::OnTrack
Whether the player is on a track (a map with a race), as opposed to the menus.
--
timerWindow.visible = Race::OnTrack() && ShowTimer;

== Race::IsActive
Whether a race is running. It stays on through checkpoint respawns. It's off in the menus, after the finish, and
for a moment during a restart.
--
if (Race::OnTrack() && Race::IsActive())
    seconds += dt;

== Race::Restarts
Restarts from the beginning of the track since the game started: Backspace, or R before the first checkpoint.
Checkpoint respawns and falls don't count. It comes from the game's own counter, so rebinding keys changes nothing.
--
// Count new restarts
int now = Race::Restarts();
if (now > seenRestarts)
    restarts += now - seenRestarts;
seenRestarts = now;

== Race::RunId
The run the player is on: a new number for every new run (a restart), the same through checkpoint respawns; -1 off a
track. The ball also gets a new one when a race starts after the pre-race screen, so count while `IsActive()`.
--
int run = Race::RunId();
if (Race::IsActive() && run != lastRun && lastRun >= 0)
    retries++;
lastRun = run;

== Race::IsComplete
Whether the run has been finished.
--
if (Race::IsComplete() && !wasComplete)
    completions++;
wasComplete = Race::IsComplete();

== Race::TrackKey
The track, as a key to keep records by: `map:<map>` for the game's own tracks, `custom:<Workshop id or local>:<file>`
for custom ones. "" until the race UI has loaded.
--
string key = Race::TrackKey();
if (key != "")
    Storage::Set("best:" + key, "" + best);

== Race::TrackName
The track's name as its header shows it (the game's own tracks show their number, "01").
--
nameText.text = Race::TrackName();

== Race::TrackAuthor
Who made the track, as the header shows it; "" on the game's own tracks.
--
authorText.text = Race::TrackAuthor() == "" ? "" : "by " + Race::TrackAuthor();

== Race::AuthorTime
The track's author time in seconds, from the medal row; 0 until the race has started.
--
double t = Race::AuthorTime();

== Race::IsCustomTrack
Whether the track is a custom one (Workshop or local).
--
if (Race::IsCustomTrack())
    Log::Info("a custom track");

== Race::GetInput
What the player is steering with right now, however they control the ball: `x` right, `y` forward (-1 to 1), and
whether jump is held. False off a track.
--
double x, y;
bool jump;
if (Race::GetInput(x, y, jump) && jump)
    jumpLight.visible = true;

== Race::SetPaused
Pauses or unpauses the game, as its own pause does (plugins keep running). Returns false if it couldn't.
--
bool pausedByUs = !Race::IsPaused() && Race::SetPaused(true);
// ... later
if (pausedByUs)
    Race::SetPaused(false);

== Race::IsPaused
Whether the game is paused.
--

    Race::SetPaused(true);

== Race::SaveBall
The ball's state as text: where it is, how it's turned, how fast it's going and spinning, and the camera. "" when
there's no ball. Keep it as long as you like; give it to `LoadBall`.
--

== Race::LoadBall
Puts the ball back in a saved state, with its speed (`momentum`) or standing still. It always makes the run a practice

== Race::StartPractice
Makes this run a practice run: the timer stops and shows 999:999.999, checkpoints and the finish stop responding, and

--

== Race::IsPractice
Whether this run is a practice run.
--

== Hud::Elements
The parts of the HUD on screen now; empty off a track. `Name`, `Label`, `Shown` and `ParentShown` answer about the

array<string>@ parts = Hud::Elements();

string name = Hud::Name(key);

== Hud::Shown
Whether the part is on screen (it and everything it sits in are visible).

Whether what the part sits in is on screen: a part the game hides for now (a split before the first checkpoint) is

== Hud::SetLayout
Moves a part by x, y pixels from where the game puts it, sizes it (1 = its own size) and sets its mode:

@@ Editor
The track editor. Pieces are identified by `int` ids. An id stops working once its piece is deleted: the functions
taking it return false or skip it. Positions are in game units (`x`, `y`, `z`, with `z` up), rotations in degrees.
`Select`, `DuplicateSelection` and `RotatePieces` do their work through the game's editor. The game's time for
that doesn't count against the plugin's time budget (up to 5 seconds a frame).

== Editor::IsOpen
Whether the track editor is running.
--
section.visible = Editor::IsOpen();
if (!Editor::IsOpen())
    return;

== Editor::Selection
The selected pieces.
--
array<int>@ selected = Editor::Selection();
Log::Info(selected.length() + " pieces selected");

== Editor::Placed
Pieces placed from the palette this frame. Pastes and duplicates aren't included.
--
// Put every new piece on whole-unit coordinates
array<int>@ placed = Editor::Placed();
for (uint i = 0; i < placed.length(); i++)
{
    double x, y, z;
    if (Editor::GetLocation(placed[i], x, y, z))
        Editor::SetLocation(placed[i], Round(x), Round(y), Round(z));
}

== Editor::GetLocation
A piece's position. Returns false if the piece no longer exists.
--
double x, y, z;
if (Editor::GetLocation(id, x, y, z))
    Log::Info("at " + x + ", " + y + ", " + z);

== Editor::GetRotation
A piece's rotation in degrees: pitch, yaw, roll. Returns false if the piece no longer exists.
--
double pitch, yaw, roll;
Editor::GetRotation(id, pitch, yaw, roll);

== Editor::SetLocation
Moves a piece. After moving selected pieces, call `Select` with them so the editor's gizmo follows.
--
Editor::SetLocation(id, x + 100, y, z);    // 100 units along X
Editor::Select(Editor::Selection());

== Editor::SetRotation
Rotates a piece to an absolute rotation in degrees: pitch, yaw, roll.
--
// Face the other way
double pitch, yaw, roll;
Editor::GetRotation(id, pitch, yaw, roll);
Editor::SetRotation(id, pitch, yaw + 180, roll);

== Editor::ViewForward
The direction the editor camera is looking, as a unit vector.
--
// 500 units in front of the camera
double fx, fy, fz;
Editor::ViewForward(fx, fy, fz);
Editor::SetLocation(id, x + fx * 500, y + fy * 500, z + fz * 500);

== Editor::Select
Selects exactly these pieces, with the editor's own highlight and gizmo.
--
// Select the copies after duplicating
Editor::Select(copies);

== Editor::DuplicateSelection
Copies the selected pieces in place and returns the copies, which are left selected.
--
array<int>@ copies = Editor::DuplicateSelection();
if (copies.length() == 0)
    Log::Warn("nothing selected to copy");

== Editor::RotatePieces
Turns pieces about a point by the given degrees around the world X, Y and Z axes (X first, then Y, then Z). Both
their positions and their rotations turn.
--
// Turn the selection 90 degrees around the vertical axis through its centre
array<int>@ ids = Editor::Selection();
double cx = 0, cy = 0, cz = 0;
for (uint i = 0; i < ids.length(); i++)
{
    double x, y, z;
    Editor::GetLocation(ids[i], x, y, z);
    cx += x / ids.length(); cy += y / ids.length(); cz += z / ids.length();
}
Editor::RotatePieces(ids, cx, cy, cz, 0, 0, 90);
Editor::Select(ids);

== Editor::SetTabCycling
While on, Tab and Shift+Tab move between the nine transform boxes in the details panel (location, rotation, scale;
X, Y, Z).
--
// On only while the editor is open
Editor::SetTabCycling(Editor::IsOpen());

== Editor::SetRotateAroundCenter
While on, rotating two or more pieces turns them about the centre of the selection instead of the last selected
piece. The same as `SetRotateMode(Editor::RotateAroundCenter)` (on) or `SetRotateMode(Editor::RotateDefault)` (off).
--
[Setting name="Rotate multiple pieces around their centre"]
bool RotateAroundCenter = false;

void OnSettingsChanged()
{
    Editor::SetRotateAroundCenter(RotateAroundCenter);
}

== Editor::SetRotateMode
How rotating two or more pieces works: `Editor::RotateDefault` (the editor's own: about the last selected piece),
`Editor::RotateAroundCenter` (about the centre of the selection) or `Editor::RotateMirrored` (each piece turns in
place, and the pieces on the two sides of the selection's centre turn opposite ways, as mirror images; the side of
the last selected piece turns the way you drag).
--
Editor::SetRotateMode(Editor::RotateMirrored);

== Editor::GetRotateMode
The rotate mode in use (`SetRotateMode`).
--
if (Editor::GetRotateMode() == Editor::RotateMirrored)
    Log::Info("mirrored");

== Editor::NextClick
The next click on the world (not on the editor's panels) since the last call, oldest first, as the editor handled it:
the piece clicked (-1 for none; found by the editor's own pick), the keys held (`Editor::ClickShift`, `ClickCtrl`, `ClickAlt`, and
`ClickOnGizmo` when the click was on the move/rotate/scale gizmo) and whether that piece was selected before the
click. The game's own clicks: a plain click selects just that piece; Shift and Ctrl add it; neither removes.
Returns false when there are none left.
--
// Shift/Ctrl on a selected piece takes it out of the selection
int piece, keys;
bool wasSelected;
while (Editor::NextClick(piece, keys, wasSelected))
{
    if (piece < 0 || (keys & Editor::ClickOnGizmo) != 0)
        continue;
    if ((keys & (Editor::ClickShift | Editor::ClickCtrl)) != 0 && wasSelected)
    {
        array<int>@ selection = Editor::Selection();
        selection.removeAt(selection.find(piece));
        Editor::Select(selection);
    }
}

== Editor::Pieces
Every piece of the open map.
--
Log::Info(Editor::Pieces().length() + " pieces");

== Editor::PieceClass
What kind of piece it is (its class name, e.g. `BP_Ramp_Curve1_C`), or "" if it no longer exists. With the
position, enough to find a piece again when the map is opened later (ids only last while it is open).
--
string kind = Editor::PieceClass(id);

== Editor::MapName
The name of the map open in the editor, as its header shows it; "" for a new map before it is saved.
--
string key = "groups:" + Editor::MapName();

== Editor::Typing
Whether a text box has the keyboard (the map name, a transform box, a search box, or a plugin's text input): keys
pressed now are being typed, so hotkeys should leave them alone.
--
if (Input::Pressed(Input::G) && !Editor::Typing())
    GroupSelection();

== Editor::AddToolbarChoice
Adds a button to the editor's toolbar, after the world/local toggle (the globe), in the toolbar's own style: an icon
and a dropdown of `options`, starting at `selected`. The icon is a game texture ("/Game/...") or a PNG in your
plugin's folder. Returns its number for `ToolbarChoice`. The button is removed when the plugin stops.
--
int rotateChoice = Editor::AddToolbarChoice("/Game/Art/UI/Textures/Editor/t_rotateIcon.t_rotateIcon",
                                            {"default", "center", "mirrored"}, 0);

== Editor::ToolbarChoice
The option a toolbar button shows now (its index), or -1 if there is no such button.
--
int chosen = Editor::ToolbarChoice(rotateChoice);

== Editor::SetToolbarChoice
Shows another option on a toolbar button.
--
Editor::SetToolbarChoice(rotateChoice, 0);

== Editor::AddHotkey
Adds a row to the editor's key list (the panel the info button shows), after the game's single-key rows: a key image
(a game texture "/Game/..." or a PNG in your plugin's folder) and what the key does. Handling the key is up to the
plugin. Removed when the plugin stops. With a third argument, a second image, the row reads "first + second" (a
modifier and a key or mouse button).
--
Editor::AddHotkey(Plugins::Folder() + "keyboard_g.png", "group");
Editor::AddHotkey("/Game/Art/UI/Textures/KeyboardMouse/keyboard_alt.keyboard_alt", "select one piece",
                  "/Game/Art/UI/Textures/KeyboardMouse/mouse_left.mouse_left");

@@ Replay
The replay being watched: a ghost's run, with the camera following it. Times are in seconds.

== Replay::IsActive
Whether a replay is being watched.
--
window.visible = Replay::IsActive();

== Replay::Time
How far into the replay playback is, in seconds.
--
timeText.text = FormatTime(Replay::Time()) + " / " + FormatTime(Replay::Length());

== Replay::Length
The replay's length in seconds, or a negative number while it's unknown (a downloaded replay fills it in once it has
loaded).
--
double length = Replay::Length();
if (length > 0)
    slider.value = float(Replay::Time() / length);

== Replay::Seek
Jumps playback to a time in seconds.
--
if (slider.dragging)
    Replay::Seek(slider.value * Replay::Length());

== Replay::Restart
Starts the replay again from the beginning.
--
if (restartButton.Clicked())
    Replay::Restart();

== Replay::CameraMode
The current camera mode: `Replay::Default`, `Replay::Follow3D` or `Replay::Free`.
--
if (Replay::CameraMode() == Replay::Free)
    hintText.text = "right mouse to look, WASD to move, E/Q up and down";

== Replay::CameraDistance
How far the replay camera stays from the ball, in whole units, or `0` for the game's own (375 units).
--
distanceText.text = "" + int(Replay::CameraDistance());

== Replay::SetCameraDistance
Sets how far the camera stays from the ball, in whole units (a fraction is rounded). It's the length of the replay
camera's arm in the default camera, and the chase distance in follow 3D. `0` goes back to the game's own.
--
// A slider from 150 to 1500 units
if (distanceSlider.dragging)

== Replay::SeeThrough
Whether see-through is on.
--
seeThroughBox.checked = Replay::SeeThrough();

== Replay::SetSeeThrough
With `true`, anything between the camera and the ball turns to glass while it's in the way, and the default camera
is no longer pushed in towards the ball by it. Pieces get their own look back a moment after they're clear. The free
camera isn't affected.
--
if (seeThroughBox.Changed())
    Replay::SetSeeThrough(seeThroughBox.checked);

== Replay::SetCameraMode
Sets the camera: `Replay::Default` (the game's own), `Replay::Follow3D` (behind the ball along its direction of
travel, turning smoothly), or `Replay::Free` (fly around: hold the right mouse button to look, WASD to move, E/Q
up and down, Shift for speed).
--
Replay::SetCameraMode(Replay::Follow3D);

@@ Cosmetics
Custom balls, hats and goal explosions (the Customize page's **bfx**). Each one gets a tile in a **custom** section at
the bottom of its tab, and choosing it works like choosing one of the game's. See the
[custom cosmetics guide](../../guides/cosmetics.md) for models and how it all fits together; most plugins use
[Cosmetic Kit](https://github.com/AnythingGoes-ballest/ballest-cosmetic-kit) rather than calling these directly, so
the player's choice is remembered.

Custom cosmetics are only worn on the player's own ball (the menu ball and the racing ball). The game's save, and
what other players see, keep the last game cosmetic chosen. Files (images, models) must be inside the plugins folder.
Ids must be unique per kind; start them with your plugin's id.

== Cosmetics::AddBall
Adds a ball. `AddBall(id, name, image, preview, model)`:

| Argument | What it is |
|---|---|
| `id` | A unique key for this ball, never shown to players. What the player wears is remembered by it, so keep it the same across versions. Start it with your plugin's id and a dot so no two plugins pick the same one: `"my-balls.planet"`. |
| `name` | The ball's name, shown in the game: `"planet"`. |
| `image` | The ball's texture: the full path of a PNG in your plugin's folder, twice as wide as it is tall (1024x512). Left to right goes once around the ball, top to bottom from pole to pole. Or `""` for a clear ball (the game's snow globe glass), to show a `model` inside it. |
| `preview` | The picture on its tile on the Customize page (a PNG in your folder), or `""` to show the texture. |
| `model` | Optional: a [model file](../../guides/cosmetics.md#models) of 3D parts built around the ball and rolling with it (raised details, lights, a spinning blade), or `""` for none. |

Returns false, and logs why, if it can't be added.
--
string f = Plugins::Folder();       // this plugin's own folder (where planet.png is)
Cosmetics::AddBall("my-balls.planet",       // id: "<plugin id>.<ball>"
                   "planet",                // name on its tile
                   f + "planet.png",        // texture (1024x512)
                   f + "planet_tile.png",   // tile picture
                   f + "rings.txt");        // model: rings around it ("" for none)

== Cosmetics::AddHat
Adds a hat. `AddHat(id, name, mesh, scale, preview, model)`:

| Argument | What it is |
|---|---|
| `id` | A unique key, as for balls: `"my-hats.cone"`. |
| `name` | Its name, shown in the game. |
| `mesh` | A mesh asset from the game or engine to wear (`"/Engine/BasicShapes/Cone.Cone"`), or `""` when the hat is a `model` instead. |
| `scale` | Its size where the game puts hats (the top of the ball): 1 is as it is; the engine's 1 m shapes want about 0.45. |
| `preview` | The picture on its tile, or `""` for none. |
| `model` | Optional: a [model file](../../guides/cosmetics.md#models) built on the top of the ball, or `""`. |
--
string f = Plugins::Folder();
// a mesh hat
Cosmetics::AddHat("my-hats.cone", "cone", "/Engine/BasicShapes/Cone.Cone", 0.45, f + "cone.png", "");
// a hat made from a model file
Cosmetics::AddHat("my-hats.basket", "fruit basket", "", 1.0, f + "basket.png", f + "basket.txt");

== Cosmetics::AddBfx
Adds a goal explosion, based on one of the game's. `AddBfx(id, name, base, scale, preview, effect, sound)`:

| Argument | What it is |
|---|---|
| `id` | A unique key, as for balls: `"my-bfx.confetti"`. |
| `name` | Its name, shown in the game. |
| `base` | One of the game's goal explosions to start from (a data asset path, such as `"/Game/Art/DataAssets/GoalExplosions/Fire1/DA_Fire1.DA_Fire1"`). |
| `scale` | Its size: 1 is the same as the base. |
| `preview` | The picture on its tile, or `""` for none. |
| `effect` | Optional: another of the game's Niagara effects to play instead of the base's, or `""`. |
| `sound` | Optional: another of the game's sounds to play instead of the base's, or `""`. |

It plays at checkpoints and in the Customize preview.
--
Cosmetics::AddBfx("my-bfx.confetti", "confetti",
                  "/Game/Art/DataAssets/GoalExplosions/Fire1/DA_Fire1.DA_Fire1",   // base
                  1.0,                                                             // scale
                  Plugins::Folder() + "confetti.png",                              // tile picture
                  "/Game/Art/NS_BallExplosion.NS_BallExplosion",                   // effect: the confetti burst
                  "/Game/Sound/Menus/SFX_ConfettiGun.SFX_ConfettiGun");            // sound

== Cosmetics::Count
How many custom cosmetics of a kind there are.
--
Log::Info(Cosmetics::Count(Cosmetics::Ball) + " custom balls");

== Cosmetics::Equip
Wears a custom cosmetic (its id), or `""` for the game's own. False if there's no such custom cosmetic. Use it to put
back what the player wore last time.
--
Cosmetics::Equip(Cosmetics::Ball, Storage::Get("ball", ""));

== Cosmetics::Equipped
The custom cosmetic the player wears, or `""` while it's one of the game's. It changes when the player picks a tile.
--
Storage::Set("ball", Cosmetics::Equipped(Cosmetics::Ball));

@@ Leaderboard
The leaderboard on the right while you're in a map.

== Leaderboard::Players
How many players have a time on the leaderboard on screen inside a map (Steam's count for that board), or -1 when
there isn't one on screen or Steam hasn't answered yet.
--
int players = Leaderboard::Players();
if (players > 0)
    Log::Info(players + " players on this track");

== Leaderboard::SetTitleNote
Shows a short note after the leaderboard's title, kept there when the game rebuilds its screens; `""` removes it. It
goes when the plugin stops. If two plugins set one, the last one shows.
--
Leaderboard::SetTitleNote("· 12,345 players");
